## 二、Monorepo 目录结构

```
assets-plateform/
├── apps/
│   ├── backend/                  ← Tauri 桌面应用（Rust 后端）
│   │   └── src-tauri/            ← Rust 项目根（Cargo.toml）
│   │       ├── src/
│   │       │   ├── main.rs       ← 入口
│   │       │   ├── lib.rs        ← Tauri Builder 初始化 + 命令注册
│   │       │   ├── api/          ← Axum HTTP REST API
│   │       │   ├── commands/     ← Tauri IPC 命令
│   │       │   ├── database/     ← PostgreSQL 数据库层
│   │       │   ├── engine/       ← Skill 引擎（智能体相关）
│   │       │   ├── service/      ← 业务逻辑层
│   │       │   ├── storage/      ← 文件存储（S3/MinIO）
│   │       │   ├── utils/        ← 工具函数
│   │       │   └── workflow/     ← 工作流引擎
│   │       └── tauri.conf.json
│   └── web/                      ← Next.js 前端
│       └── src/                  ← React + Mantine UI + 页面组件
├── packages/
│   └── shared/                   ← 共享 TypeScript 类型
│       └── src/types/            ← user / asset / category / department 类型
├── docs/                         ← 设计文档
└── script/                       ← 安装/构建脚本
```

## 五、前端 (`apps/web`) 概览

- **框架**: Next.js 16 (Webpack) + React 19
- **UI**: Mantine v9 全套组件
- **编辑器**: TipTap + MDXEditor
- **图标**: Tabler Icons
- **图表**: ECharts
- **图可视化**: Cytoscape (知识图谱)
- **状态**: Zustand
- **表单校验**: Zod
- **表格导出**: xlsx
- **QR 码**: qrcode
- **测试**: Jest + Playwright + Storybook
- **可观测**: OpenTelemetry Web SDK

**前端通过两种方式与后端通信**：
1. Tauri IPC（桌面模式）：`@tauri-apps/api` invoke 调用 Rust commands
2. Axum HTTP API（Web 模式）：通过 `@tauri-apps/plugin-http` 或 fetch 调用 REST 接口

## 六、核心业务流程

### 6.1 资产管理系统主流程

```
用户登录 → 角色鉴权 → 租户选择
  ├─ 固定资产管理（增删改查 + 资产卡片）
  ├─ 无形资产管理（增删改查）
  ├─ 审批流程（领用/归还/调拨/维修/报废/采购）
  ├─ 知识库管理（树形目录 + 知识条目 + RAG 检索）
  ├─ 知识图谱（实体关联可视化）
  ├─ LLM 聊天对话（多厂商支持）
  └─ 系统管理（用户/角色/租户/编号规则/文件上传）
```

### 6.2 RAG 知识问答流程

```
文档上传 → 解析(PDF/DOCX) → 文本切片 → 向量化(LLM) → 存入向量库
  ↓
用户提问 → 语义检索 → 获取相关片段 → LLM 生成回答 → 返回前端
```

### 6.3 Skill 智能体流程

```
前端调用 execute_skill
  → skill_registry 查找 Skill 元数据
  → (TODO) Python 子进程执行脚本
  → 返回执行结果
```

## 七、关键特性

1. **多租户**：PostgreSQL Schema 隔离，支持租户切换
2. **读写分离**：主库写入 + 从库加权轮询读取
3. **LLM 多厂商**：OpenAI/Claude/通义千问/Ollama 统一适配器
4. **大文件分片上传**：两步提交 + 断点续传
5. **审批工作流**：集成 wfe-core 引擎
6. **全链路可观测**：OpenTelemetry 指标/Trace/日志
7. **RAG 知识库**：文档切片 + 向量检索 + LLM 增强回答
8. **Skill 智能体**：内置 15 个 Skill（Python 运行时待实现）
