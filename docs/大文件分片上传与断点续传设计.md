# 大文件分片上传与断点续传设计

> 目标：支持 GB 级大文件分片上传、断点续传、并发加速，存储后端为支持 S3v4 协议的 RustFS/MinIO/AWS S3。
> 设计原则：**前端直传 S3，Rust 只做协调**，服务器不经过文件数据，带宽和 CPU 开销几乎为零。

---

## 一、整体架构

```
前端 (Next.js)                    Rust Axum API                    S3 (RustFS/MinIO)
    │                                  │                                │
    │  ① 初始化上传 (POST /init)       │                                │
    │  {filename, size, mime}          │                                │
    │ ──────────────────────────────►  │  创建 upload_id                │
    │                                  │  ────────────────────────────►  │
    │  {upload_id, chunk_size,         │  ← upload_id, presigned URLs   │
    │   presigned_urls[]}              │                                │
    │ ◄──────────────────────────────  │                                │
    │                                  │                                │
    │  ② 分片直传 S3 (PUT presigned)   │                                │
    │  ┌─ chunk 1 ──────────────────────────────────────────────────►  │
    │  ├─ chunk 2 ──────────────────────────────────────────────────►  │
    │  ├─ ...                                                          │
    │  └─ chunk N ──────────────────────────────────────────────────►  │
    │                                  │                                │
    │  ③ 上报分片 (POST /{id}/chunk)   │                                │
    │  {part_number, etag}             │                                │
    │ ──────────────────────────────►  │  更新 received_chunks[]       │
    │                                  │                                │
    │  ④ 查询进度 (GET /{id}/progress) │                                │
    │ ◄── {received_chunks, pct}       │                                │
    │                                  │                                │
    │  ⑤ 完成合并 (POST /{id}/complete)│                                │
    │ ──────────────────────────────►  │  ──► S3 CompleteMultipart     │
    │ ◄── {file_url, etag}             │                                │
    │                                  │                                │
    │  ⑥ 取消上传 (DELETE /{id})       │                                │
    │ ──────────────────────────────►  │  ──► S3 AbortMultipartUpload  │
```

### 为什么选择 S3 原生分片（前端直传）？

| 对比项 | S3 原生分片（本方案） | 服务端中转 |
|--------|---------------------|-----------|
| 流量路径 | 前端直传 S3 | 前端 → Rust → S3 |
| 服务器负载 | 几乎为零 | 需要中转全部数据 |
| 带宽消耗 | 不占用应用服务器带宽 | 双倍带宽（进 + 出） |
| 断点续传 | S3 MultipartUpload 原生支持 | 需自行维护 |
| 大文件支持 | S3 支持最大 5TB | 受限于服务器磁盘/内存 |
| 实现复杂度 | 低（S3 SDK 封装） | 高 |

```rust
    pub secret_key: String,
    pub bucket: String,
    pub public_base_url: String,

    pub fn from_env() -> Self { ... }

pub struct S3Client {
    client: aws_sdk_s3::Client,
    config: S3Config,
}

impl S3Client {
    /// 从环境配置创建
    pub async fn from_env() -> Self { ... }

    /// 从自定义配置创建
    pub async fn new(config: S3Config) -> Self { ... }

    // ---------- Multipart Upload ----------

    /// 创建分片上传，返回 S3 UploadId
    pub async fn create_multipart_upload(
        &self, bucket: &str, key: &str, mime_type: &str,
    ) -> Result<String, S3Error>;

    ) -> Result<String, S3Error>;  // 返回 ETag

    /// 取消分片上传

        &self, bucket: &str, key: &str, upload_id: &str,
    ) -> Result<(), S3Error>;

    // ---------- 对象操作 ----------

    /// 生成文件下载的 Presigned URL
    pub async fn presign_get_object(
        &self, bucket: &str, key: &str, expires_in: Duration,

    pub async fn delete_object(&self, bucket: &str, key: &str) -> Result<(), S3Error>;
```

```rust
    pub updated_at: DateTime<Utc>,
}

/// 初始化上传返回
pub struct UploadInitResult {
    pub upload_id: String,           // 数据库记录 ID
    pub s3_upload_id: String,        // S3 UploadId
    pub chunk_size: i64,
    pub total_chunks: i32,
    pub presigned_urls: Vec<String>, // 每个分片的直传 URL
}

/// 上传进度
pub struct UploadProgress {
    pub status: String,
    pub received_chunks: Vec<i32>,
    pub total_chunks: i32,
    pub progress_pct: i32,
}

/// 完成上传返回
pub struct UploadCompleteResult {
    pub file_url: String,
    pub etag: String,
}

// ======================== UploadManager ========================

pub struct UploadManager {
    pool: PgPool,
    s3: S3Client,
    config: S3Config,
}

impl UploadManager {
    pub fn new(pool: PgPool, s3: S3Client, config: S3Config) -> Self;

    /// 初始化上传
    /// 1. 生成 S3 Object Key（按日期/UUID 组织）
    /// 2. 计算分片大小和数量
    /// 3. 调用 S3 CreateMultipartUpload
    /// 4. 生成所有分片的 Presigned URL
    /// 5. 保存上传记录到数据库
    /// 6. 返回 upload_id + presigned_urls
    pub async fn init(
        &self, schema: &str,
        filename: &str, file_size: i64, mime_type: &str,
        created_by: i64,
    ) -> Result<UploadInitResult, String>;

    /// 上报分片上传完成
    /// 前端上传分片到 S3 后，调用此接口告知后端
    pub async fn report_chunk(
        &self, schema: &str,
        upload_id: i64, part_number: i32, etag: &str,
    ) -> Result<(), String>;

    /// 查询上传进度
    /// 返回已接收的分片列表和进度百分比
    pub async fn get_progress(
        &self, schema: &str, upload_id: i64,
    ) -> Result<UploadProgress, String>;

    /// 完成上传（合并分片）
    /// 1. 检查所有分片是否已上传
    /// 2. 调用 S3 CompleteMultipartUpload
    /// 3. 更新数据库状态为 completed
    /// 4. 返回文件访问 URL
    pub async fn complete(
        &self, schema: &str, upload_id: i64,
    ) -> Result<UploadCompleteResult, String>;

    /// 取消上传
    /// 1. 调用 S3 AbortMultipartUpload
    /// 2. 更新数据库状态为 cancelled
    pub async fn abort(
        &self, schema: &str, upload_id: i64,
    ) -> Result<(), String>;

    /// 清理过期上传（定时任务用）
    /// 删除超过指定小时数未完成的上传记录
    pub async fn clean_expired(
        &self, schema: &str, expire_hours: i64,
    ) -> Result<i64, String>;  // 返回清理的记录数
}
```

### 3.2 `services/uploadService.ts` — 上传 API 工具类

纯 API 封装，不依赖任何 UI 框架，可在任何项目中使用。

```typescript
// ======================== 类型定义 ========================

export interface InitUploadResponse {
  uploadId: string;
  s3UploadId: string;
  chunkSize: number;
  totalChunks: number;
  presignedUrls: string[];
}

export interface UploadProgress {
  status: string;
  receivedChunks: number[];
  totalChunks: number;
  progressPct: number;
}

export interface UploadCompleteResponse {
  fileUrl: string;
  etag: string;
}

// ======================== UploadService ========================

export class UploadService {
  private baseUrl: string;

  constructor(baseUrl = '/api') {
    this.baseUrl = baseUrl;
  }

  /** 初始化分片上传 */
  async init(
    filename: string,
    fileSize: number,
    mimeType: string
  ): Promise<InitUploadResponse> {
    const res = await fetch(`${this.baseUrl}/upload/init`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ filename, fileSize, mimeType }),
    });
    if (!res.ok) throw new Error(`初始化上传失败: ${res.statusText}`);
    return res.json();
  }

  /** 上传单个分片到 S3 Presigned URL */
  async uploadChunk(
    presignedUrl: string,
    chunk: Blob,
    partNumber: number
  ): Promise<string> {
    const res = await fetch(presignedUrl, {
      method: 'PUT',
      body: chunk,
      headers: { 'Content-Length': chunk.size.toString() },
    });
    if (!res.ok) throw new Error(`分片 ${partNumber} 上传失败: ${res.statusText}`);
    return res.headers.get('ETag') || '';
  }

  /** 上报分片上传完成 */
  async reportChunk(
    uploadId: string,
    partNumber: number,
    etag: string
  ): Promise<void> {
    const res = await fetch(`${this.baseUrl}/upload/${uploadId}/chunk`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ partNumber, etag }),
    });
    if (!res.ok) throw new Error(`上报分片失败: ${res.statusText}`);
  }

  /** 查询上传进度 */
  async getProgress(uploadId: string): Promise<UploadProgress> {
    const res = await fetch(`${this.baseUrl}/upload/${uploadId}/progress`);
    if (!res.ok) throw new Error(`查询进度失败: ${res.statusText}`);
    return res.json();
  }

  /** 完成分片上传 */
  async complete(uploadId: string): Promise<UploadCompleteResponse> {
    const res = await fetch(`${this.baseUrl}/upload/${uploadId}/complete`, {
      method: 'POST',
    });
    if (!res.ok) throw new Error(`完成上传失败: ${res.statusText}`);
    return res.json();
  }

  /** 取消上传 */
  async abort(uploadId: string): Promise<void> {
    const res = await fetch(`${this.baseUrl}/upload/${uploadId}`, {
      method: 'DELETE',
    });
    if (!res.ok) throw new Error(`取消上传失败: ${res.statusText}`);
  }
}
```

```typescript
  /** 进度回调 */
  onProgress?: (pct: number) => void;
  /** 完成回调 */
  onComplete?: (result: UploadCompleteResponse) => void;
  /** 错误回调 */
  onError?: (err: string) => void;

  totalBytes: number;

  /** 取消上传 */
  cancel: () => Promise<void>;
  /** 重试上传 */
  retry: () => Promise<void>;
}

// ======================== Hook ========================

export function useChunkedUpload(
  options?: UseChunkedUploadOptions
): UseChunkedUploadReturn {
  // ... 实现细节

  // 核心逻辑：
  // 1. start: 调用 init → 分片 → 并发上传 → 上报 → complete
  // 2. pause: AbortController.abort()
```

## 四、断点续传核心逻辑

```
用户选择文件上传
    │
    ▼
检查 localStorage 是否有未完成的 upload_id
    │
    ├── 有 → 调用 GET /upload/{id}/progress
    │         │
    │         ├── status = completed
    │         │   └── 直接返回文件 URL，跳过上传
    │         │
    │         ├── status = uploading
    │         │   ├── 对比 received_chunks 和 total_chunks
    │         │   ├── 只上传缺失的分片
    │         │   └── 继续上报 → complete
    │         │
    │         └── status = cancelled/failed
    │             └── 清除 localStorage，重新初始化
    │
    └── 无 → 调用 POST /upload/init 开始新上传
              └── 保存 upload_id 到 localStorage
```

### 断点续传关键代码

```typescript
// useChunkedUpload.ts 中的 resume 逻辑

async function resume() {
  const savedId = localStorage.getItem(storageKey);
  if (!savedId) return;

  // 查询当前进度
  const progress = await uploadService.getProgress(savedId);
  
  if (progress.status === 'completed') {
    // 已经上传完成，直接返回
    return;
  }

  // 只上传缺失的分片
  const uploadedSet = new Set(progress.receivedChunks);
  const missingChunks = chunks.filter((_, i) => !uploadedSet.has(i + 1));

  // 并发上传缺失分片
  await uploadMissingChunks(missingChunks);
}
```

#### 8.4.2 `FileUploader` 组件（带 UI）

```tsx
// src/components/FileUploader.tsx

'use client';

import React, { useState, useCallback, useRef, useEffect } from 'react';
import { UploadService } from '@/services/uploadService';

// ======================== 类型定义 ========================

export interface FileUploaderProps {
  accept?: string;
  maxSize?: number;
  multiple?: boolean;
  concurrency?: number;
  onUploadComplete?: (result: {
    fileUrl: string;
    originalName: string;
    fileSize: number;
  }) => void;
  onUploadError?: (error: string) => void;
}

interface UploadTask {
  id: string;
  file: File;
  progress: number;
  status: 'pending' | 'uploading' | 'paused' | 'completed' | 'error';
  speed: string;        // 上传速度，如 "2.3 MB/s"
  error?: string;
  fileUrl?: string;
}

// ======================== 图标组件 ========================

const UploadIcon = () => (
  <svg className="w-12 h-12 text-gray-300" fill="none" stroke="currentColor" viewBox="0 0 24 24">
    <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={1.5}
      d="M7 16a4 4 0 01-.88-7.903A5 5 0 1115.9 6L16 6a5 5 0 011 9.9M15 13l-3-3m0 0l-3 3m3-3v12" />
  </svg>
);

const FileIcon = ({ ext }: { ext: string }) => {
  const iconMap: Record<string, JSX.Element> = {
    pdf: <span className="text-red-500 text-lg">📄</span>,
    doc: <span className="text-blue-500 text-lg">📝</span>,
    docx: <span className="text-blue-500 text-lg">📝</span>,
    xls: <span className="text-green-500 text-lg">📊</span>,
    xlsx: <span className="text-green-500 text-lg">📊</span>,
    jpg: <span className="text-purple-500 text-lg">🖼️</span>,
    jpeg: <span className="text-purple-500 text-lg">🖼️</span>,
    png: <span className="text-purple-500 text-lg">🖼️</span>,
    zip: <span className="text-yellow-500 text-lg">📦</span>,
    rar: <span className="text-yellow-500 text-lg">📦</span>,
  };
  return iconMap[ext.toLowerCase()] || <span className="text-gray-500 text-lg">📄</span>;
};

const CloseIcon = () => (
  <svg className="w-4 h-4" fill="none" stroke="currentColor" viewBox="0 0 24 24">
    <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M6 18L18 6M6 6l12 12" />
  </svg>
);

// ======================== 工具函数 ========================

function formatSize(bytes: number): string {
  if (bytes === 0) return '0 B';
  const k = 1024;
  const sizes = ['B', 'KB', 'MB', 'GB', 'TB'];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return parseFloat((bytes / Math.pow(k, i)).toFixed(1)) + ' ' + sizes[i];
}

function formatSpeed(bytesPerSec: number): string {
  return formatSize(bytesPerSec) + '/s';
}

function getFileExt(filename: string): string {
  return filename.split('.').pop() || '';
}

// ======================== 主组件 ========================

export function FileUploader({
  accept = '.pdf,.docx,.jpg,.png,.zip,.rar',
  maxSize = 10 * 1024 * 1024 * 1024,  // 10GB
  multiple = false,
  concurrency = 3,
  onUploadComplete,
  onUploadError,
}: FileUploaderProps) {
  const [isDragOver, setIsDragOver] = useState(false);
  const [tasks, setTasks] = useState<UploadTask[]>([]);
  const [showModal, setShowModal] = useState(false);
  const fileInputRef = useRef<HTMLInputElement>(null);
  const uploadServiceRef = useRef(new UploadService());

  // ======================== 文件选择处理 ========================

  const validateFile = useCallback((file: File): string | null => {
    if (file.size > maxSize) {
      return `文件 ${file.name} 超过大小限制 ${formatSize(maxSize)}`;
    }
    if (accept) {
      const ext = '.' + getFileExt(file.name);
      const allowed = accept.split(',').map(s => s.trim().toLowerCase());
      if (!allowed.includes(ext.toLowerCase()) && !allowed.includes('.*')) {
        return `文件 ${file.name} 类型不支持，支持格式: ${accept}`;
      }
    }
    return null;
  }, [accept, maxSize]);

  const addFiles = useCallback((files: FileList | File[]) => {
    const newTasks: UploadTask[] = [];
    const fileArray = Array.from(files);

    for (const file of fileArray) {
      const error = validateFile(file);
      newTasks.push({
        id: Math.random().toString(36).substr(2, 9),
        file,
        progress: 0,
        status: error ? 'error' : 'pending',
        speed: '0 B/s',
        error: error || undefined,
      });
    }

    setTasks(prev => [...prev, ...newTasks]);
    setShowModal(true);

    // 自动开始上传
    newTasks.filter(t => t.status === 'pending').forEach(task => {
      startUpload(task.id);
    });
  }, [validateFile]);

  // ======================== 拖拽事件 ========================

  const handleDragOver = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(true);
  }, []);

  const handleDragLeave = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(false);
  }, []);

  const handleDrop = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(false);
    if (e.dataTransfer.files.length > 0) {
      addFiles(e.dataTransfer.files);
    }
  }, [addFiles]);

  // ======================== 上传逻辑 ========================

  const startUpload = useCallback(async (taskId: string) => {
    const task = tasks.find(t => t.id === taskId);
    if (!task) return;

    setTasks(prev => prev.map(t =>
      t.id === taskId ? { ...t, status: 'uploading' } : t
    ));

    try {
      const uploadService = uploadServiceRef.current;

      // 1. 初始化上传
      const initResp = await uploadService.init(
        task.file.name, task.file.size, task.file.type
      );

      // 2. 分片
      const chunks: Blob[] = [];
      for (let start = 0; start < task.file.size; start += initResp.chunkSize) {
        chunks.push(task.file.slice(start, start + initResp.chunkSize));
      }

      // 3. 并发上传
      let uploadedCount = 0;
      const totalChunks = chunks.length;
      let lastLoaded = 0;
      let lastTime = Date.now();

      const uploadOneChunk = async (partNumber: number): Promise<void> => {
        const presignedUrl = initResp.presignedUrls[partNumber - 1];
        const chunk = chunks[partNumber - 1];

        const etag = await uploadService.uploadChunk(presignedUrl, chunk, partNumber);
        await uploadService.reportChunk(initResp.uploadId, partNumber, etag);

        uploadedCount++;
        const pct = Math.round((uploadedCount / totalChunks) * 100);

        // 计算速度
        const now = Date.now();
        const elapsed = (now - lastTime) / 1000;
        if (elapsed > 0.5) {
          const bytesPerSec = (uploadedCount * initResp.chunkSize - lastLoaded) / elapsed;
          setTasks(prev => prev.map(t =>
            t.id === taskId ? { ...t, progress: pct, speed: formatSpeed(bytesPerSec) } : t
          ));
          lastLoaded = uploadedCount * initResp.chunkSize;
          lastTime = now;
        } else {
          setTasks(prev => prev.map(t =>
            t.id === taskId ? { ...t, progress: pct } : t
          ));
        }
      };

      // 并发控制
      const workers = Array.from({ length: concurrency }, async (_, i) => {
        while (true) {
          const taskState = tasks.find(t => t.id === taskId);
          if (taskState?.status === 'paused') break;

          const partNumber = i + 1;
          if (partNumber > totalChunks) break;

          await uploadOneChunk(partNumber);
        }
      });

      await Promise.all(workers);

      // 4. 完成合并
      const result = await uploadService.complete(initResp.uploadId);

      setTasks(prev => prev.map(t =>
        t.id === taskId ? {
          ...t, progress: 100, status: 'completed',
          fileUrl: result.fileUrl, speed: '✅ 上传完成',
        } : t
      ));

      onUploadComplete?.({
        fileUrl: result.fileUrl,
        originalName: task.file.name,
        fileSize: task.file.size,
      });

    } catch (err: any) {
      setTasks(prev => prev.map(t =>
        t.id === taskId ? { ...t, status: 'error', error: err.message } : t
      ));
      onUploadError?.(err.message);
    }
  }, [tasks, concurrency, onUploadComplete, onUploadError]);

  // ======================== 操作处理 ========================

  const pauseUpload = useCallback((taskId: string) => {
    setTasks(prev => prev.map(t =>
      t.id === taskId && t.status === 'uploading'
        ? { ...t, status: 'paused' as const }
        : t
    ));
  }, []);

  const resumeUpload = useCallback((taskId: string) => {
    startUpload(taskId);
  }, [startUpload]);

  const cancelUpload = useCallback((taskId: string) => {
    setTasks(prev => prev.filter(t => t.id !== taskId));
  }, []);

  const retryUpload = useCallback((taskId: string) => {
    setTasks(prev => prev.map(t =>
      t.id === taskId ? { ...t, status: 'pending', progress: 0, error: undefined } : t
    ));
    startUpload(taskId);
  }, [startUpload]);

  // ======================== 渲染 ========================

  return (
    <>
      {/* 上传按钮 */}
      <div className="flex items-center gap-2">
        <button
          onClick={() => fileInputRef.current?.click()}
          className="flex items-center gap-2 px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 transition-colors text-sm font-medium"
        >
          <svg className="w-4 h-4" fill="none" stroke="currentColor" viewBox="0 0 24 24">
            <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M12 4v16m8-8H4" />
          </svg>
          上传文件
        </button>

        <input
          ref={fileInputRef}
          type="file"
          className="hidden"
          accept={accept}
          multiple={multiple}
          onChange={(e) => e.target.files && addFiles(e.target.files)}
        />
      </div>

      {/* 上传弹窗 */}
      {showModal && (
        <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50"
          onClick={() => setShowModal(false)}>
          <div className="bg-white rounded-xl shadow-2xl w-[640px] max-h-[80vh] flex flex-col"
            onClick={e => e.stopPropagation()}>

            {/* 弹窗标题 */}
            <div className="flex items-center justify-between px-6 py-4 border-b">
              <h2 className="text-lg font-semibold text-gray-800">上传文件</h2>
              <button onClick={() => setShowModal(false)}
                className="p-1 hover:bg-gray-100 rounded-lg transition-colors">
                <CloseIcon />
              </button>
            </div>

            {/* 拖拽区域 */}
            <div
              className={`mx-6 mt-4 p-8 border-2 border-dashed rounded-xl text-center transition-colors cursor-pointer
                ${isDragOver ? 'border-blue-500 bg-blue-50' : 'border-gray-300 hover:border-gray-400'}`}
              onDragOver={handleDragOver}
              onDragLeave={handleDragLeave}
              onDrop={handleDrop}
              onClick={() => fileInputRef.current?.click()}
            >
              <div className="flex flex-col items-center gap-2">
                <UploadIcon />
                <p className="text-gray-600 font-medium">
                  {isDragOver ? '释放文件以上传' : '拖拽文件到此处，或点击选择'}
                </p>
                <p className="text-xs text-gray-400">
                  支持 {accept} 格式，单个文件最大 {formatSize(maxSize)}
                </p>
              </div>
            </div>

            {/* 文件列表 */}
            <div className="flex-1 overflow-y-auto px-6 py-4 space-y-2">
              {tasks.length === 0 ? (
                <div className="text-center py-8 text-gray-400 text-sm">
                  暂无文件，请拖拽或选择文件上传
                </div>
              ) : (
                tasks.map(task => (
                  <div key={task.id}
                    className="border rounded-lg p-3 transition-colors hover:border-gray-300">

                    {/* 文件信息 */}
                    <div className="flex items-center gap-3">
                      <FileIcon ext={getFileExt(task.file.name)} />
                      <div className="flex-1 min-w-0">
                        <p className="text-sm font-medium text-gray-700 truncate">
                          {task.file.name}
                        </p>
                        <p className="text-xs text-gray-400">
                          {formatSize(task.file.size)}
                        </p>
                      </div>

                      {/* 状态操作 */}
                      <div className="flex items-center gap-2">
                        {task.status === 'uploading' && (
                          <>
                            <button onClick={() => pauseUpload(task.id)}
                              className="text-xs px-2 py-1 text-gray-500 hover:bg-gray-100 rounded">
                              暂停
                            </button>
                            <button onClick={() => cancelUpload(task.id)}
                              className="text-xs px-2 py-1 text-red-500 hover:bg-red-50 rounded">
                              取消
                            </button>
                          </>
                        )}
                        {task.status === 'paused' && (
                          <>
                            <button onClick={() => resumeUpload(task.id)}
                              className="text-xs px-2 py-1 text-blue-500 hover:bg-blue-50 rounded">
                              继续
                            </button>
                            <button onClick={() => cancelUpload(task.id)}
                              className="text-xs px-2 py-1 text-red-500 hover:bg-red-50 rounded">
                              取消
                            </button>
                          </>
                        )}
                        {task.status === 'completed' && (
                          <span className="text-xs text-green-600 font-medium">✅ 完成</span>
                        )}
                        {task.status === 'error' && (
                          <>
                            <button onClick={() => retryUpload(task.id)}
                              className="text-xs px-2 py-1 text-orange-500 hover:bg-orange-50 rounded">
                              重试
                            </button>
                            <button onClick={() => cancelUpload(task.id)}
                              className="text-xs px-2 py-1 text-red-500 hover:bg-red-50 rounded">
                              移除
                            </button>
                          </>
                        )}
                      </div>
                    </div>

                    {/* 进度条 */}
                    {task.status !== 'completed' && task.status !== 'error' && (
                      <div className="mt-2">
                        <div className="flex items-center gap-2">
                          <div className="flex-1 h-1.5 bg-gray-200 rounded-full overflow-hidden">

                    {task.error && (

            {/* 底部统计 */}
            <div className="px-6 py-3 border-t flex items-center justify-between text-sm text-gray-500">
              <span>
                {tasks.filter(t => t.status === 'completed').length} / {tasks.length} 完成
```

```tsx
function formatSize(bytes: number): string {
  if (bytes === 0) return '0 B';
  const k = 1024;
  const sizes = ['B', 'KB', 'MB', 'GB', 'TB'];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return parseFloat((bytes / Math.pow(k, i)).toFixed(1)) + ' ' + sizes[i];
}

function formatDate(dateStr: string): string {
  const d = new Date(dateStr);
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}
```
